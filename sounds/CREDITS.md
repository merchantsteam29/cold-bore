# Sound credits

Gunshots: **The Free Firearm Sound Library** ("Prepared SFX Library"), from OpenGameArt:
https://opengameart.org/content/the-free-firearm-sound-library. Released **CC0 (no rights reserved)**, so no credit
is required; credited here anyway, with thanks.

Converted to mono 48 kHz 16-bit, trimmed and normalised. Source takes:

| Game file | Recording |
|---|---|
| pistol, pistol_far | Walther PPQ, 9mm (near / mid distance) |
| pistol45, pistol45_far | Colt 1911, .45 ACP |
| magnum, magnum_far | Smith & Wesson 642, .38 Special (pitched down in game for .50 AE / .500) |
| smg, smg_far | Carl Gustav M45, 9mm |
| rifle, rifle_far | AR-15, 5.56×45 |
| ak_1, ak_2, ak_far | AK-47 and Norinco SKS, 7.62×39 |
| battle, battle_far | Tikka T3, .30-06 (stands in for 7.62×51 / 6.8×51) |
| sniper_1/2, sniper_far_1/2 | Springfield 1917 (.30-06) and Mosin Nagant (7.62×54R) |
| shotgun_1/2/3, shotgun_far_1/2 | Charles Daly pump, Benelli Nova, Winchester Model 12 (12 gauge) |

The .50 BMG uses the sniper recordings pitched down. Reloads, impacts, casings and explosions are still synthesized.
